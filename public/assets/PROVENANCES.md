# Provenance des médias

- `terre-nasa.jpg` : photographie Apollo 17, NASA, 7 décembre 1972. https://svs.gsfc.nasa.gov/30613 . La fausse légende utilisée dans une manche est annoncée au corrigé.
- `skatepark-ia.png` : image générée pour cet atelier avec l’outil de génération d’images OpenAI, septembre 2026. Aucun jeune réel représenté.
- `plat-ia.jpg` : ancien média fourni par Matthieu, déclaré généré avec Gemini dans le support original ; conservé comme ressource de remplacement.
- `beat-atelier.wav` : synthèse déterministe de notes, accords et percussions ; partition fixe, sans modèle audio génératif. Le code de préparation a été produit avec l’aide d’une IA. Cela permet de distinguer génération musicale par modèle et exécution d’un programme.
- `motif.wav` et `mouvement.mp4` : anciens exemples programmés, conservés ; aucune captation personnelle. L’animation vidéo suit des trajectoires mathématiques.
- Extrait de Verlaine : « Il pleure dans mon cœur », Romances sans paroles, 1874, domaine public. La manche distingue l’auteur de l’œuvre de l’outil qui la recopie.
- Avis et citation fictifs : exemples préparés, non témoignages réels ; la citation institutionnelle du bonus est volontairement inventée.
