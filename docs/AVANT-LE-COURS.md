# Répétition avant le 23 septembre

1. Sur le vrai ordinateur et le vidéoprojecteur, activer l’écran étendu. Ouvrir Projeter, déplacer la fenêtre, puis Afficher les slides. Vérifier la lisibilité au fond de la salle.
2. Tester Suivante, Retour, Réponse, écran noir, un audio et une vidéo. Contrôler le volume avant l’arrivée des jeunes.
3. Ouvrir le même espace privé sur l’appareil de secours ; vérifier une retouche et une prise de main. Revenir au pupitre principal.
4. Exporter une sauvegarde complète après les dernières retouches. Copier les PDF et les médias sur clé USB. Ouvrir la copie de secours sur chaque machine et tester hors ligne.
5. Préparer cinq jeux de missions/enquêtes et dix mémos/billets. Ne pas exiger de compte personnel des jeunes ; prévoir les exemples préparés.
6. Tester le micro seulement si le cadre a été convenu avec la MJC. Expliquer que toute voix peut déclencher le mot-clé. Garder les boutons et les raccourcis accessibles.
7. Sans API active, utiliser ChatGPT vocal séparément ou une démonstration explicitement préparée. Le cours ne dépend pas de cette démonstration.
8. Faire un passage chronométré des transitions. En cas de retard : supprimer les bonus, réduire une restitution, garder les pauses et la vérification.

Les tests logiciels ne remplacent pas cette répétition sur le matériel réel. L’IA est un outil de l’atelier ; les échanges, les essais et les vérifications en restent le cœur.
